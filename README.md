SportsPlay

INSTALLATION INSTRUCTIONS

Install Xampp: https://www.apachefriends.org/

After installation run go inside Xampp application folder and search for folder "htdocs". 

Download or pull the github repository folder. Drag and drop the sportsplay folder into the htdocs folder within the xampp directory.

Go to xampp and run both MySQL Database and Apache Web Server.

Go to browser and in the browser box go to http://localhost:3307/SportsPlay-main/ (this may vary depending on which port you are running the server aswell as the folder name, adjust accordingly)

You may need to make changes to the DB for testing purposes. You may find the credentials under the website/config/config.php and then login into Adminer or PHPmyAdmin.
